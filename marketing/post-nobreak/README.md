# Post 1080x1080 — "Caiu a luz? Seu Wi-Fi continua" (600 Mega + Mini Nobreak)

Imagem quadrada para anúncio no Instagram/Facebook. Foto gerada por IA (Seedream V4.5 via Kairogen, 2 gerações: cena + correção),
textos aplicados por HTML/CSS e renderizados com Chromium para garantir grafia, acentos e margem de 10%.

- `out/post-caiu-a-luz-nobreak-1080x1080.png` — arquivo final (PNG). `.jpg` é a mesma imagem comprimida.
- `bg.jpg` — foto base 2048x2048 sem texto.
- `post.html` — layout, gradação de cor da marca (camadas roxo/magenta) e os 4 textos. Para alterar preço ou texto, edite aqui.
- `shot.js` — renderiza: `node marketing/post-nobreak/shot.js` (variável `GUIDE=1` mostra a margem de 10%).

Conferir antes de publicar: "600 MEGA", "R$ 139,90/MÊS", "NOBREAK EM COMODATO" e "INSTALAÇÃO GRÁTIS" vieram do briefing.
